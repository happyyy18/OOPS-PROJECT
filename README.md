ATM Simulation System

The ATM Simulation System is an Object-Oriented Programming (OOPS) project that simulates the basic functionalities of an Automated Teller Machine (ATM). It allows users to securely access their accounts using a PIN and perform various banking operations such as checking account balance, withdrawing money, depositing money, and changing their PIN.

This project demonstrates important OOPS concepts such as Classes, Objects, Encapsulation, Inheritance, Polymorphism, and Abstraction. It provides a simple and user-friendly interface to understand how ATM systems work.

Features
Secure PIN verification
Check account balance
Withdraw money
Deposit money
Change ATM PIN
Exit safely
Technologies Used
Programming Language:Java
Concept: Object-Oriented Programming (OOPS)
Objective

The main objective of this project is to implement real-world banking operations using OOPS principles while improving programming, problem-solving, and logical thinking skills.
